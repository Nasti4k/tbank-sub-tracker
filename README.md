# tbank sub tracker

Telegram-бот, который по PDF-выписке **Т-Банка** находит **активные подписки** — регулярные списания с одной и той же суммой и описанием.

## Возможности

- Принимает PDF-выписку из Т-Банка через Telegram
- Извлекает операции из текста выписки
- Группирует одинаковые списания (описание + сумма)
- Считает подписку активной, если:
  - операция встречалась не меньше чем в **3 разных месяцах**
  - в каждом месяце — **не больше одного** такого списания
  - есть списание за **прошлый месяц**

## Как это работает

1. Пользователь запускает бота командой `/start`
2. Нажимает кнопку **«Получить список текущих подписок»**
3. Отправляет PDF-файл выписки из Т-Банка
4. Бот анализирует документ и отвечает списком активных подписок

Пример ответа:

```text
Активные подписки:
SPOTIFY | -299.00 ₽
YANDEX PLUS | -299.00 ₽
```

## Требования

- Python 3.10+
- Telegram Bot Token ([@BotFather](https://t.me/BotFather))

## Установка

```bash
git clone https://github.com/Nasti4k/tbank-sub-tracker.git
```

Создайте виртуальное окружение и установите зависимости:

```bash
python -m venv .venv

# Windows
.venv\Scripts\activate

# macOS / Linux
source .venv/bin/activate

pip install -r requirements.txt
```

## Настройка

В файле `main.py` укажите токен бота:

```python
token = 'YOUR_TOKEN'
```

Замените `YOUR_TOKEN` на токен от [@BotFather](https://t.me/BotFather).

## Запуск

```bash
python main.py
```

После запуска бот начнёт принимать сообщения в Telegram.

## Ограничения

- Изначально рассчитан на **PDF-выписки Т-Банка**
- Работает с **текстовыми** PDF (не со сканами)
- Парсер ориентирован на формат операций Т-Банка: даты, суммы со знаком валюты, описание, номер карты
- Выписки других банков могут не распознаваться
- Подписка определяется эвристически по повторяемости списаний, а не по официальному списку сервисов банка
